Tujuan Pembelajaran
🎯 Tujuan Belajar: Memahami pengelolaan data dalam kehidupan masyarakat
1Menjelaskan konsep data, informasi, dan pentingnya pengelolaan data dalam kehidupan sehari-hari.
2Mengidentifikasi jenis-jenis data (kuantitatif, kualitatif, pribadi, publik) pada situasi nyata di lingkungan sekitar.
3Mengumpulkan dan mencatat data secara sistematis menggunakan tabel sederhana.
4Mengolah dan menyajikan data dalam bentuk diagram/grafik agar mudah dipahami orang lain.
5Menganalisis data secara kritis untuk mengambil keputusan serta menjaga etika dan keamanan data pribadi.
Materi Pembelajaran
📊
Apa itu Data?
Data adalah fakta atau catatan mentah tentang suatu keadaan, misalnya jumlah siswa atau suhu ruangan, yang belum memiliki makna sebelum diolah.
🔢
Jenis-Jenis Data
Data kuantitatif berupa angka (jumlah, nilai), data kualitatif berupa kategori/sifat (warna, pendapat). Ada pula data pribadi dan data publik.
🔄
Siklus Pengelolaan Data
Data dikelola melalui tahap: Kumpulkan → Simpan → Olah → Sajikan → Gunakan untuk mengambil keputusan.
🛠️
Alat Pengumpulan Data
Data dapat dikumpulkan melalui survei, observasi langsung, kuesioner, maupun sensor sederhana di lingkungan sekitar.
📈
Menyajikan Data
Data yang sudah diolah disajikan dalam tabel, diagram batang, diagram lingkaran, atau grafik garis agar mudah dipahami.
🔒
Etika & Keamanan Data
Data pribadi harus dijaga kerahasiaannya, tidak dibagikan sembarangan, dan digunakan dengan izin serta tanggung jawab.
